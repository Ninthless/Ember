# Ember

[English](README.md) | [中文](README.zh-CN.md)

Ember 是一个 Windows 桌面软件，用来给抖音单聊续火花。登录发生在窗口里的聊天页。软件读取这个页面上的会话，可以向今天还没发过的人发一条互动表情。

## 能做成什么

- 在聊天页登录。正常退出后，登录会留在这个软件里。不用粘贴 Cookie。
- 看每个单聊和群聊：名字、火花、天数、最近一条、你今天发过没有、对方今天发过没有。
- 给今天待发的单聊和群聊一条一条续。排除掉的会话不发。测试发送只发测试列勾上的会话。
- 窗口开着的时候，按两个钟点运行。自动发送默认是关的，要自己打开。

火花算今天点亮，仍然要双方都发过消息。Ember 只负责发出你这一边。

## 页面

**火花。** 顶上三个数字：今天待发、已点亮、已排除。表格在窗口里面滚动。**刷新列表** 会再读一次会话，不会发消息。

**定时。** 两个时间，默认是 `10:05` 和 `21:05`，可以改。**到点自动续火** 默认关闭。到点时窗口要开着；软件关了就不会发。

**登录。** 下面整块是聊天页。**刷新页面** 会重载这个页面，然后再读一次登录态。不会发消息。

## 发送规则

| 操作 | 会发给谁 |
| --- | --- |
| 一键续火 | 今天待发、且没有排除的单聊和群聊。今天已经发过的会话会跳过。 |
| 到点自动续火 | 和一键续火同一批会话，按两个钟点发。 |
| 测试发送 | 只发测试列勾上的会话。排除了的不发。今天发过的其余会话仍会再发。 |
| 排除 | 勾上的会话不会进入一键续火、到点续火和测试发送。一个都不排除时，今天待发的都会发。 |

没有会话短号、没有票据，或其他会话类型，不发。消息是一条发完再发下一条，每条回包后稍等一下。聊天页把登录弹掉时，这一轮停止。

列表会在发送之后更新，聊天页有新动态时更新，隔一小段时间也会再读一次。**刷新列表** 是立刻做同一次读取。

## 设置

选项写在 Electron userData 目录里的 `settings.json`。在 Windows 上是 `%APPDATA%\spark-desktop\settings.json`。里面有定时、排除的 id，以及测试发送勾选的 id。群聊记的是会话 id。没有聊天登录信息。以前的发送范围开关不再读取。

## 发布

第一个发布版本是 `0.1.0`。推送的标签名是 `v` 加上 `package.json` 里的 `version`，例如 `v0.1.0`。GitHub Actions 会跑测试，打出 Windows 安装包和便携版，并挂到对应的 GitHub Release 上。

这条工作流没有给文件签名。Windows SmartScreen 第一次打开时可能会提示。

## 开发

需要 Node.js 和 npm。这个仓库在 Windows 上开发。

```bash
npm install
npm run dev
```

`npm run dev` 会打开 Ember 窗口。起来之后进 **登录**，在聊天页登入，再回到 **火花**。列表会自己出现。

| 命令 | 结果 |
| --- | --- |
| `npm test` | 跑本地单元测试。测试不会请求抖音。 |
| `npm run typecheck` | 检查渲染层和共享代码的类型。 |
| `npm run build` | 产物写到 `out/`。 |
| `npm run dist:win` | 先构建 `out/`，再把 Windows 安装包和便携版写到 `release/`。 |
| `npm run preview` | 打开构建好的软件。 |

构建产物、依赖和本地环境文件不进 git。见 `.gitignore`。

## 目录

| 路径 | 作用 |
| --- | --- |
| `src/main` | 窗口、聊天页会话、设置文件 |
| `src/preload` | 窗口读写设置用的那一层 |
| `src/renderer` | 侧栏、火花、定时、登录、嵌入的聊天页 |
| `src/shared` | 列表解析、发送判断和测试 |
| `electron-builder.yml` | Windows 安装包和便携版 |
| `.github/workflows` | 持续集成，以及推送版本标签时的发布 |

npm 包名仍是 `spark-desktop`。产品名是 Ember。
